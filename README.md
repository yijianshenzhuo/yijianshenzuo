## 三、快速上手：10 分钟写出第一章 🚀

**怎么操作**
1. 打开网站即自动登录，无需注册
2. 「小说管理」→「新建小说」：先选读者（男频 / 女频），再选题材（题材随读者过滤，男频 19 + 女频 18 = 34 类）、加标签、定目标章数
3. 进入小说概览页，选择「深度创作模式」按菜单逐步创作（想全自动则选「一键模式」→ 一键写作 / 一键仿写）
4. 依次点各页面的「AI智写」：批量生成人物与关系 → 生成章节细纲 → 生成第一章正文；进度条右侧可展开「AI思考」看实时过程
5. 用「正文编辑」右侧面板打磨，满意后用「智能优化」润色

**给你的价值**：约 10 分钟拿到第一章可写可用的初稿，先尝到「写出来」的甜头。

> 💡 小贴士：「AI智写」都支持批量生成，一次可以生成多条。
> ▶ 下一步：想写得快，看「一键写全本」；想写得细，看「世界设定」和「正文编辑」。

### ⚡ 一键写全本

> 拆爆款、仿文风、写全本，三件套一键直达——会看就会写，点按钮出书。

**一键拆书**（无需先建小说，页面独立于任何一本书）
- 拆解爆款公式、秒懂写作逻辑：把一本喜欢的书拆成可直接套用的设定、大纲与素材
- 四种导入方式：📖 书名 + 作者、🔗 阅读页网址、📄 上传文件（TXT / EPUB / Markdown）、🏆 扫榜（起点：热销 / 新书 / 阅读指数 / 收藏 / 月票 / 推荐榜，番茄：各频道排行，七猫：排行榜，每榜 ≥15 条，勾选书目直接拆解）
- 真实 **23 阶段**进度：查找资源 → 下载 TXT → 小说定义 / 创意 / 全书总纲 / 分卷大纲 / 章节细纲 / 人物 / 道具 / 势力 / 地域 / 境界与等级 / 世界规则 / 金手指 / 技能 / 事件 / 伏笔 / 历史事件 / 桥段 / 描写 / 文风 / 热梗 / 特色词汇（2 步导入 + 21 个拆解模块）
- **进度按真实 AI 调用计算**：以「已完成 LLM 调用次数 ÷ 本次总调用次数」推进（正文按 50 万字切片逐片拆解），单调不回退；AI 拆解全部完成前，后续模块统一显示「待拆解」，不提前展示条数与结果，完成后一次性展示 21 模块结果
- **AI思考**：进度条右侧可展开「AI思考」，实时查看当前思考与流式输出，直到拆解结束
- 进度区实时详情：是否找到小说、TXT 字数、各模块已拆条数（2 秒刷新，拆一条显示一条）
- **拆解完成自动入库**（公共拆解库，所有人可见可用），点「保存到我的模板库」按 21 个模块分流进你的私人素材库，重复保存自动去重
- **全章节解析**：逐章精读（每批 ≤15 章、每章正文节选 ≤1200 字、封顶约 360 章，超出部分用规则摘要兜底），产出完整总纲 / 分卷 / 细纲，杜绝「大纲只有 3 章」
- 质量底线：拆不出就返回空、**绝不编造**；热梗只收有传播力的梗、特色词汇只收题材专属词、命名输出「姓 + 名」全名并附寓意解析
- 文风蒸馏：正文节选 ≤6000 字，五层蒸馏（语言DNA / 结构 / 选题 / 素材 / 认知框架）
- 后台执行：手机息屏、刷新、切走页面都不丢，回来自动恢复

> 💡 怎么操作：左侧「一键写全本 → 一键拆书」→ 选导入方式（书名最省事，也可网址、文件或扫榜勾选榜单书目）→ 点「搜索、导入并拆解」→ 实时看进度：书找到没、正文多少字、各模块拆出几条 → 完成后点「保存到我的模板库」分流进你的私人素材库。
> 💡 小贴士：书名搜不到时，改用网址或上传文件直接提供正文。

**一键仿写**（有参照的原创）
- 新人入门不会写？直接套用大神作品的写作套路，一键仿写大神文风
- 两段式页面：上部选参考书 + 只读 21 库预览 + 模块参照勾选 + 每模块「仿写微创新」输入框；下部配置 + 开始仿写
- 参数：参照小说（弹窗选择器、可搜索）、章节范围、内容处理（续写 / 覆盖）；参照模块由上部 21 库勾选决定（默认全选，未勾选不参照），仿写深度按综合仿写，题材冲突固定「优先当前题材」；至少勾选一个参照模块
- 仿写微创新按模块注入，如「把主角改成女性」「都市换成仙侠」，实现「参考它、又不只是它」
- 约束：仅参照结构与风格，**不照抄原文**；缺数据时自动回退题材映射默认值；生成章节入库并标记仿写来源

> 💡 怎么操作：左侧「一键写全本 → 一键仿写」→ 选参考书（拆解小说库，可搜索）→ 上方只读预览那本书的 21 库内容、勾选要参照的模块并在要改的模块下写「仿写微创新」→ 配置章节范围、续写或覆盖 → 点「开始仿写」，后台自动完成：世界设定 → 大纲 → 批量正文 → 智能优化；进度条右侧可展开「AI思考」。

**一键写作**（纯原创全自动流水线）
- 一句话写全本：填好基础设定与章节范围，世界设定、剧情大纲、逐章正文全自动生成，摸鱼也能轻松日更
- 执行链：章节范围配置 → 生成世界设定 → 生成剧情大纲 → 批量正文（约 3000 字/章 ±20%）→ 智能优化（热梗植入 / 去AI味 / 润色，可拖拽排序 / 开关）→ 落盘保存
- 已有章节时启动前选择「续写」（保留现有世界设定 / 大纲 / 章节）或「覆盖」（清空所选章节范围并重建世界设定与大纲）；无章节时按续写执行
- 后处理默认按题材自动调整：历史 / 悬疑 / 古代言情、科幻 / 末世默认关闭热梗植入；都市 / 玄幻 / 言情 / 游戏竞技 / 短篇脑洞默认全开

- 严格复用各功能页自身的 Prompt，你自定义的基础设定会传入每一步

### 🗺️ 世界设定

> 构建合理又吸引人的特殊设定，打造玄妙奇幻的世界——金手指、功法招式、武功秘籍、灵丹妙药都能一键生成。世界设定分「人物设定管理 / 世界观管理 / 法则体系设定 / 剧情时序管理」四页，把「抽象规则」与「具象事物」分开管理，设定越攒越完整，长篇创作也不崩人设、不崩设定。

- 所有条目新建 / 编辑弹窗与字段均提供「AI智写」；顶部全局「AI批量智写」可一次生成多条，新建弹窗内也可只生成当前这一条
- 各页模板库均按 21 库拆分后的对应库提供（人物库 / 道具库 / 势力库 / 地域库 / 境界与等级库 / 世界规则库 / 金手指库 / 技能库 / 事件库 / 伏笔库 / 历史事件库）

**人物设定管理**
- 角色档案字段齐全：姓名、角色定位（主角 / 配角 / 反派）、身世背景、**心头刺**（一句话执念，主角每个关键选择都要能追溯到它，是行为逻辑的最高优先级约束）、性格标签、**人物成长线**（起点状态 → 终点状态 → 转变过程，记录角色完整弧光）
- 角色列表按定位筛选（主角 / 配角 / 反派），卡片网格展示，支持**多选批量删除**与**批量 AI 优化**
- 分层 AI 智写：字段级「AI智写」精修单个字段；新建 / 编辑人物内「AI智写」一次生成或优化全部属性；页面右上角「AI智写」批量生成人物并**同步自动创建人物关系**
- 「📚 人物设定库」按「身世背景 / 心头刺」推荐 Top 10 模板，导入时连同预设关系边、性格标签、成长线一起完整带入
- 「关系」页签支持手工增删与 AI 生成；「人物图谱」页签只读查看，图谱一律中文标注（师徒 / 宿敌 / 盟友…），关系网一目了然

**世界观管理**（道具 / 势力 / 地域 三页签）
- **道具**：属性键值对 + 拥有者（从角色下拉选择或手输），按类型筛选快速定位
- **势力**：组织架构 + 成员名单，成员从人物库弹窗勾选，也可手输人名
- **地域**：风貌特征标签，搭建小说的地理版图
- 三页签各自独立模板库（道具库 / 势力库 / 地域库）与 AI 智写，模板推荐跟随当前小说题材

**法则体系设定**（境界与等级 → 世界规则 → 金手指 → 技能 四页签）
- **境界与等级**：直接录入等级序列（自定义等级名与逐级描述）；页面不再提供「境界体系类型」选项——体系类型由右上角「境界与等级库」选模板带入，或由 AI 依据题材自动确定（玄幻预填修仙阶位、科幻预填异能等级）
- **世界规则**：自由录入世界底层规则——如魔法守恒定律、灵气复苏时间线、修炼瓶颈阈值、科技树限制，按「规则名称 + 具体内容 + 对剧情的影响」结构化沉淀
- **金手指**：类型多选（小说可有多个金手指）+ 名称 + 触发条件 + 能力描述 + 限制 / 代价，主角爽点核心一次配齐
- **技能**：功能分类（攻击 / 防御 / 增益 / 减益 / 治疗 / 控制 / 身法 / 感知 / 特殊 / 被动）× 体系分类（武技 / 魔法 / 神通 / 异能 / 机甲技能 / 游戏技能），可手录、AI 批量生成，或从**技能库 1000+ 精品网文技能**按分类多选导入
- 四个页签各自独立的模板库与 AI 智写界面，互不混用

**剧情时序管理**（事件 → 伏笔 → 历史事件 → 时序泳道图 四页签）
- **事件**：微观剧情时间线，每条事件必须关联具体章节号，可排序、按章节过滤
- **伏笔**：记录埋设章节 + 回收状态（未回收 / 已回收，回收时必填回收章节），埋了多少、收了没一目了然
- **历史事件**：宏观世界史，年代 + 事件名称 + 事件描述 + 对当前故事的影响，让世界「有过去」
- **时序泳道图**：事件按章节纵向排列、按**角色分列**，同角色相邻事件自动连线（虚线 + 箭头，表达「A 的行动导致 B 的反应」），支持 50%~200% 缩放与平移——动笔前先看全局时间线，伏笔回收不漏
- 事件 / 伏笔 / 历史事件各自独立的模板库（事件库 / 伏笔库 / 历史事件库）与 AI 智写

**信息同步（自动）**
- 正文编辑器顶部「保存正文后自动同步世界设定与剧情大纲」开关（默认开启）：每次保存章节正文后，自动提取本章新出现的人物（含关系）/ 道具 / 势力 / 地域 / 法则（金手指 / 境界 / 规则 / 技能）/ 时序事件，与现有设定按名称去重合并后自动入库
- 全自动执行、失败静默不影响写作，无需手动复制粘贴上下文

> 💡 怎么操作：在「世界设定」四页分别打磨——人物（含关系图谱）、世界观（道具 / 势力 / 地域）、法则体系（境界 / 规则 / 金手指 / 技能）、剧情时序（事件 / 伏笔 / 历史 + 泳道图）；写完正文保存后，设定会自动同步进来。

| 问题 | 处理方式 |

| 如何开始使用？ | 打开网站即可，系统自动创建账号；在个人中心补设密码后，可在其他设备登录同一账号 |

| 支付后页面提示异常？ | 结果页会自动向支付网关核实订单并开通会员，稍等轮询即可；长时间未开通请联系管理员 |
